Start

四步上手：装插件、启动本地后端，即可开刷。

Latest Release 的 openbiliclaw-v* 聚合页只列出同一版本的后端源码、浏览器插件包和可用桌面安装包；某个 channel 尚未发布时会显示未发布，不会回填上一版资产。普通用户直接装桌面安装包即可，开发者或想要定制源码可交给 AI 编程助手部署。

添加到 Chrome 打开 Latest 聚合页 查看 README
Gitee 源码镜像 AtomGit 源码 历史版本（123 云盘 v0.3.213） 下载插件 zip / Firefox / Safari 包
1. 装插件：支持 Chrome / Edge / Brave / Arc / Firefox / Safari，负责采集行为信号与只读会话桥接。
2. 装后端：右侧任选桌面包、AI 部署、脚本或 Docker；启动后访问 http://127.0.0.1:8420/web。

桌面安装包（开箱即用，最省事）

macOS Apple 芯片下载 OpenBiliClaw-macos-v*-arm64.dmg，Intel 下载 x64 包（如发布页提供）；退出旧版后打开 DMG，将 app 拖入应用程序并启动。桌面 Mac 包经过 Developer ID 签名与 Apple 公证，无需解除隔离命令。Windows 下载 OpenBiliClaw-windows-*-Setup.exe，支持自定义目标目录，安装后常驻菜单栏/托盘。内置免费模型与本地 BGE-M3 支持，数据统一存于 ~/OpenBiliClaw。

浏览器插件负责连接平台

浏览器插件既是推荐、反馈和聊天入口，也是平台登录态与行为信号的连接层，并为 Linux.do / V2EX / 微博等来源执行有界只读任务；微博公开 discovery 由后端完成，个人初始化才打开微博同源任务页，Cookie 不回传。最新版可从 GitHub Latest Release 下载同版本 Chrome / Firefox / Safari 包，或使用自动更新的应用商店版本。

Why it matters

推荐顺序反过来：先理解人，再找内容。

平台推荐通常先有内容池，再预测你会点什么。OpenBiliClaw 先沉淀对你的理解，再让 Agent 带着这份理解跨平台主动寻找。

01 Private

纯本地私有

数据落在本机 SQLite 与本地记忆文件里。可使用预置免费模型或自有 API Key，不需要把画像交给新的云端平台。

02 Self-improving

画像会随使用演化

跨平台行为、推荐反馈、聊天表达、兴趣与避雷探针确认，都会进入学习闭环，让系统逐步更懂你的真实偏好。

03 Proactive

主动去找，而不是等你刷

Discovery 会把心理画像翻译成搜索、趋势、关联链、远域探索和多源任务，持续维护跨平台候选池。

04 Explainable

推荐理由能看懂

每条推荐都带朋友式解释。你可以喜欢、不喜欢、补一句原因，反馈会继续影响后续发现和排序。

Learning Loop

自进化不是口号，而是一条闭环。

OpenBiliClaw 不只是抓取历史再生成一次画像。它会在实际使用中持续吸收新的行为、反馈和对话，让理解和推荐一起更新。

01

跨平台使用行为

跨平台公开内容与自定义网站/RSS 进入候选链；授权的个人信号、推荐反馈和对话进入学习事件层。

02

项目内反馈与对话

你对推荐卡片的喜欢、不感兴趣、评论，以及聊天里的明确偏好和探针回答，会成为长期理解候选。

03

心理画像持续深化

Soul Engine 会把事件转成偏好、觉察、洞察和分层画像，不只记录“看了什么”，还判断“为什么会喜欢”。

04

Agent 带着理解主动寻找

Discovery Engine 把画像变成可执行的搜索、热点、关联、探索和多源任务，补进候选池并保持来源配比。

05

推荐继续反哺理解

Recommendation Engine 选出内容、解释原因、接收反馈；下一轮画像和候选池会因此继续校准。

Sources

你的兴趣不该被单个平台切碎。

B 站、小红书、抖音、YouTube、TikTok、X、知乎、Reddit、Linux.do、Bangumi、V2EX、微博、GitHub、Instagram 与开放 Web，共用同一套理解、发现和推荐流程。

Bilibili

B 站

历史、收藏、关注、搜索、趋势、关联链和跨域探索共同提供候选。

Xiaohongshu

小红书

通过浏览器插件任务桥读取收藏、喜欢和页面内容，不由后端直接爬取。

Douyin

抖音

初始化信号走扩展任务；search、hot 和 feed 从抖音首页 DOM 操作触发，并被动收集页面响应。

YouTube

YouTube

插件读取观看历史、订阅和点赞用于画像初始化，也支持 Takeout 离线导入；日常发现由后端搜索、热门和频道内容补池。

TikTok

TikTok（正式可用）

正式可用、默认关闭。未登录可发现推荐流、话题和创作者视频；浏览器登录后可关键词搜索，需海外网络。

连接指南 · 实测范围
X / Twitter

X（Twitter）

初始化信号和 Cookie 由插件同步，后端以只读会话执行搜索、For You 与关注作者发现，推文使用文字卡片呈现。

Zhihu

知乎

初始化信号和 search / hot / feed / creator / related discovery 都走已登录浏览器插件任务。

Reddit

Reddit

saved / upvoted / subscribed 初始化走插件；日常发现默认走内置 rdt-cli（自动同步会话），不可用时自动回退插件任务。

Linux.do

Linux.do

公开 search / hot / feed / creator / related 无需登录；书签 / 点赞 / 阅读记录用已登录浏览器同源只读 GET，只回传归一化字段。

Bangumi

Bangumi

官方匿名只读 API 提供条目搜索、排名和按日期浏览；填个人令牌或公开用户名即可导入收藏用于初始化。

V2EX

V2EX

匿名公开发现覆盖 search / Node / Tab / hot / latest；已登录浏览器或可选 PAT 可只读导入本人主题、回复与收藏。

Weibo

微博

公开 discovery 覆盖 search / hot / creator；登录微博后可在初始化时通过同源只读任务导入收藏、关注和互动，Cookie 不离开浏览器。

GitHub

GitHub

官方 REST API 匿名发现公开 repository；填公开用户名即可用 starred repositories 初始化画像，PAT 可选。

Instagram

Instagram（正式可用）

正式可用、默认关闭。按话题和创作者发现内容；同一浏览器登录后可有界导入近期点赞、收藏和关注，需海外网络。

连接指南 · 实测范围
Web & RSS

通用 Web 与 RSS

在「聊一聊」粘贴网站 URL 与内容需求，自动预览 RSS / Sitemap 或静态与动态页面（macOS 托管 Ego Lite，支持应用内人工登录接管），确认订阅后加入内容发现。

Instagram 与 TikTok 均需海外网络：后端沿现有网络/代理设置，浏览器任务使用浏览器自身代理。插件默认包含两者的站点访问权限；请在设置中手动启用来源，并查看对应连接指南。

Product

一套本地后端，五种使用入口。

浏览器插件、桌面 Web、移动 Web、Flutter 原生客户端和 DSH 客户端插件共享同一套推荐、内容库、对话与画像能力；平台登录态和只读任务仍由浏览器插件承接。

浏览器插件（Chrome/Edge/Firefox/Safari） 桌面 Web (/web) 移动 Web (/m/) Flutter 原生端（iOS/Android/桌面） DSH 客户端插件 + 22 工具

桌面大屏：惊喜推荐 + 为你推荐网格

顶部惊喜推荐 Hero、按来源筛选的推荐网格与朋友式推荐理由一目了然。

灵魂画像：人格素描与深层驱动力

画像不是黑盒标签，而是随时可检查、可编辑、可质疑的自然语言人格描述与 MBTI 结构化认知。

移动端随时刷

局域网扫码或 Tailnet 直连回家，随时看惊喜推荐、池子状态与推荐理由。

推荐与即时反馈

换一批、继续看、喜欢、不感兴趣、写一句原因，每次反馈都会回流进学习闭环。

聊天调教 & 加网站

直接告诉它你想看什么、避开什么，或者丢给它一个网址，立刻帮你试采并订阅。

Architecture

技术可以讲成四层：使用入口、本地后端、智能内核、私有数据。

没有云端账号体系，也不是又一个内容平台。它是一套跑在你电脑上的个人推荐系统。

01

多端入口与浏览器扩展

Chrome / Edge / Brave / Arc / Firefox / Safari 扩展连接平台；桌面、移动 Web、Flutter 与 DSH 客户端消费同一本地服务。

02

本地后端

在你的电脑上接收事件、调度 discovery 与并发闸门，支持热重载、Tailnet / HTTPS 远程接入与跨机迁移。

03

Soul / Discovery / Recommendation

Soul 理解人，Discovery 多源找候选（含预置免费 Qwen / BGE-M3 与故障切换链），Recommendation 挑内容并生成解释。

04

SQLite 私有记忆

行为、画像、候选池、已看账本与 30 天历史留在本机，可备份、检查、清理和迁移。
