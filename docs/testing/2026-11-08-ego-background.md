## 修复与边界

原实现使用 `--no-startup-window`，随后在创建采集 tab 后最小化窗口。
本轮对官方 Ego Lite **0.6.2.9** 实测，建页至最小化之间仍能看到原生窗口。
操作系统的隐藏／后台启动也不能阻止 Ego 首次设置显示窗口。

现统一给本应用托管的官方 Ego 主程序添加 `--headless=new`，包括首次设置与
后续冷启动。没有切换 Playwright、另装 Chromium 或改动官方签名包。
临时首次设置仍操作原有 WebUI 并在完成后关闭调试端口；网站登录通过应用内的
接管截图和操作 API 完成。旧的外部宿主模式仍完全由使用者管理，不强制隐藏其窗口。
正在运行的旧宿主在下一次正常冷启动采用新参数，不中断活跃会话。
