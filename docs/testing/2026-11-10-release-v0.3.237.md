## 签名运行时与 Docker

Core 固定到 [sponsored-runtime-2026-11-10.1](https://github.com/whiteguo233/OpenBiliClaw/releases/tag/sponsored-runtime-2026-11-10.1)。五个归档和签名目录共六项附件的 SHA-256 与上传前一致，Mac 双架构分别通过 Apple 公证。新目录覆盖 Core `0.3.237`。本机 Intel 独立测试下载、验签、激活、重复安装和损坏更新回退。

Intel 运行时的三个真实短请求并发成功，关闭模型互备。Qwen3-8B 首字 0.539 秒，Qwen3.5-4B 首字 0.429 秒，各收到 6 个流式增量。BGE-M3 用时 0.344 秒，返回 1,024 维文本向量。

Docker 原始构建在 Playwright 内置 Node 处缺少 `libatomic.so.1`。修复提交 `7dbd3feb` 在安装 Chromium 之前添加 `libatomic1`，并用该提交重建容器。四个既有版本标签保留。[Docker 修复 PR](https://github.com/whiteguo233/OpenBiliClaw/pull/346) · [五平台原生及双架构 Docker 验收](https://github.com/whiteguo233/OpenBiliClaw/actions/runs/42844020452)

## 桌面安装包

Windows 普通版、Windows 内置向量版与 Apple Silicon 普通版通过安装验收后发布。两种 Mac 架构的普通版另走独立公证与冻结启动自检。[初始桌面发布](https://github.com/whiteguo233/OpenBiliClaw/actions/runs/42843316530) · [Mac 双架构构建](https://github.com/whiteguo233/OpenBiliClaw/actions/runs/42842992964)

Intel 的本机下载首次中断。通过分段续传取得完整 DMG，并核对 ZIP CRC、镜像和复制应用的 Developer ID 签名、Apple 公证票据与 Gatekeeper。该 DMG 的 SHA-256 为 `913052cd58e0f591347afd99b67aada18df23ba589876b4d224b7f3274d65ee6`，与 Actions 独立读取的摘要及两页发布资产一致。[工件摘要审计](https://github.com/whiteguo233/OpenBiliClaw/actions/runs/42849293307) · [Intel 附件发布](https://github.com/whiteguo233/OpenBiliClaw/actions/runs/42850324234)

Intel macOS 26.5.1 实机用隔离新配置启动。默认菜单栏入口在 180 秒内未响应。前台对照在 4.07 秒可访问，`/api/auth/status` 返回 `enabled=false` 和 `authenticated=true`，`/setup/` 与 `/web/` 均为 HTTP 200。macOS 15 双架构原生安装、正常启动和真实请求另见 [DMG 验收](2026-11-10-macos-dmg-live.md)。

Apple Silicon 内置向量版首次构建在复制完整应用时耗尽 DMG 卷空间。独立构建的签名应用已通过 Apple 公证，失败发生在生成安装镜像阶段。本机用正式应用结构加 1,100 MiB 测试载荷复现，宿主仍有超过 60 GiB 可用，申请 2,167 MiB 的可写镜像未能完整复制。补足分区和 HFS 元数据所需容量后，实际挂载卷为 2,606 MiB，同一应用及载荷完整复制并通过签名校验。最终压缩测试镜像约 1.47 GB。测试载荷用于验证镜像容量，正式补发使用校验过的 BGE-M3 模型。

正式 Apple Silicon 内置向量 DMG 从打包修复提交 `3ce08902` 构建，应用与镜像均获 Apple 公证，签名后冻结启动自检通过。最终 DMG 为 1,306 MiB，两页附件的 SHA-256 为 `180fec6968e3f3afab3e362497e9c4f2e0186515bab017b86624d3f31f72e77e`。应用公证回执为 `d735d7e2-b67e-4074-9a73-4996265dd53a`，镜像公证回执为 `c3a7c112-e033-45a7-a1c0-ce244e2e8dbe`。[打包修复 PR](https://github.com/whiteguo233/OpenBiliClaw/pull/347) · [正式补发](https://github.com/whiteguo233/OpenBiliClaw/actions/runs/42851455147)
