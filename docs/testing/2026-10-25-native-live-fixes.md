## 已复现的原因和修复

### 相似历史中的精确回忆

先前原始失败请求三次重放都把新暗号混为相似旧暗号。修复保留完整有界历史、时间戳和卡片关系，将“较早历史”和“最近用户发言及其后续记录”明确分区，仍作为引用记录而非新的用户指令。没有删除旧历史或硬编码暗号。

修复后的同一原始失败请求三次真实重放均正确，另两种变体也正确；证据为 `chat-replay-partitioned-results.json`。不能以早期诊断变体的结果代替最终补丁验证。

### NGA 准备误判

真实失败同时涉及 URL 脱敏语义、网页自行添加查询参数，以及 CSS 选择器证据缺少原始 href 前缀。修复为明确说明观测 URL 已脱敏，并提供保留隐私的入口比较结果；提取原始 href 属性前缀用于选择器推断。

真实 NGA 页面添加了一个额外查询参数，原入口的协议/主机、路径、请求查询参数和片段仍一致。新比较字段保留“非完全相等”的事实，同时区分入口改变与网站追加参数；入口比较结果只提供布尔值，不暴露网页新增参数的名称和值，用户提供的原入口仍按原样传给模型。没有硬编码 NGA 特例。修复包括空前缀和 href 前导空白回归。

前两轮原生失败的草稿分别为 `60af29cf-aab3-4875-9135-1aa9e859f290`、`1f7e4592-9ea9-4821-8b4f-8e089bf8f1b6`，均保留为失败证据。随后真实新增、APP 审批和份额管理成功，证明来源准备阻塞已恢复。

### 后台最小化后的原生接管截图

修复前整轮 NGA 流程在新增、审批、设置和后台采集之后，进入接管页时截图接口返回 500。官方 Ego CDP 的真实原因是窗口仍处于最小化状态，不能截图。对同一自有窗口恢复显示并等待后，同一个截图 API 返回了真实 PNG。

生产补丁 `85d95f56` 在创建人工会话和截图前恢复当前自有目标所属窗口并等待操作系统就绪。若截图期间又被后台最小化，仅对该明确错误恢复重试一次；后台任务本身不恢复窗口。持续竞争仍返回可诊断的 409，不声称实现了窗口级并发隔离。已知截图错误不再抛出无上下文的 500，也不返回伪图片。

### 原生验收脚本

假设卡可能已由后台挂在聊天中，并且尚未被懒加载列表构建。测试助手原先对尚不存在的文本使用 `.last`，在滚动开始前就抛出异常。改为让 `scrollUntilVisible` 接受可暂时为空的 finder，保持原有卡片状态和模型回复断言。此处不修改原生产品代码。

随后一轮完整聊天在新暗号和确认按钮通过后，等待第二条假设超时。纯函数重放确认测试数据与旧假设只改了时间戳、正文完全相同，新旧相似度为 0.846 / 0.838，被正常近似去重合并并保留旧标题。不是画像回写覆盖；生产去重保持不变。改用语义不同的两条初始数据，并先验证其确认前后均不会与既有隔离记录合并。证据为 `hypothesis-fixture-dedupe-proof.json`；失败轮次仍保留。
