## 本次修复与复现

1. **公共网站被误拒**：真实系统解析将公共域名返回为 `198.18.0.0/15` 的代理合成地址。修复前 Ego 公网预检连续失败；修复后仅对全部命中该范围的域名使用已有严格 DoH 校验。私网、混合答案、字面 IP 及失败的 DoH 仍拒绝；HTTP 固定验证后的地址，Ego 仍只有 DNS 预检保证。
2. **前置侧栏遮蔽新闻列表**：Solidot 的原观察达到 100 个元素，却只包含侧栏热门新闻／评论，真实模型返回 `needs_details`。固定 DOM 观察器改为让表格／article 与带链接的标题共享 16 组结构样本；总量仍为 100。修复后的真实观察包含首页新闻，模型编制、试跑、PC 审批及正式采集得到 3 条。没有站点专用选择器或伪造内容。
3. **PC 低高度布局与抽屉**：888×511 窗口原聊天记录高度仅 6px 且页面不可滚动。修复后保留最小 160px、允许纵向滚动。会话抽屉遮住外部开关的问题改由抽屉内「收起」解决；宽屏也保留开关，关闭后对话使用剩余宽度。真实输入草稿保持。

4. **空闲状态误导**：Ego 已准备且因空闲自动退出时，共享来源管理组件原来显示“尚未就绪”和准备按钮。现在显示“已准备，按需启动”，说明后台会自动唤醒；失败及外部宿主不冒充可自动启动。同步替换 PC／扩展模块文档中仍指向旧安装流程的过时说明。
