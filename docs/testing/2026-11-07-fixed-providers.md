# 固定免费 Provider 实例验收（2026-11-07）

本次继续在 `feat/unified-sponsored-providers` 上实现固定目录，替代前一轮可编辑免费模型的交互。没有修改 Rust SDK、供应商凭据、签名合同或模型请求协议；尚未合入 main 或发布应用安装包。

## 当前契约

- Qwen3-8B 与 Qwen3.5-4B 各为一个固定 LLM 实例，参与现有默认链与模块链。用户可以选择、移除链引用和调整顺序，不能修改名称、模型、启用状态、凭据、地址、认证头、推理或上下文配置，也不能复制或删除目录项。
- BGE-M3 是独立的固定 Embedding 选项：模型 `BAAI/bge-m3`、1024 维、纯文本、无用户凭据或地址。切换聊天实例不改变向量空间；可以切换到本地或自有向量 Provider。缓存、相似度阈值和备用选择仍属于现有业务策略。
- API 输出 `read_only=true`；写入时比较受保护实例的完整配置，修改或复制返回 HTTP 400 且磁盘不变。整个实例列表的替换会保留省略的内置项，兼容旧客户端，不允许通过省略来删除。
- 内置目录版本升级到 2。保留已有模型与首个实例 ID；同模型的旧重复项归并并迁移默认/模块链引用；缺少的另一个模型只补入目录，不自动加入链。不覆盖同名自有端点或密钥。
- 仅改变默认链时，运行时更新已注册实例的顺序，保留 API 进程的在途请求、后台任务对象与向量服务；独立 worker 仍按现有配置代际重载，持久化任务可恢复。实例配置或模块链改变仍走完整安全重建。
