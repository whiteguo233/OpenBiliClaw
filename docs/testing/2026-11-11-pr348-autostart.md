# PR #348 自启动环境来源修复验收

基线：PR head `78242f0d`。本次在独立分支 `fix/pr348-autostart-restart`
中补齐更新重启和测试隔离，不修改用户配置或真实 OS 登录项。

## 行为与回归

- 重启使用 `build_restart_env()` 生成环境副本，通过 `os.execve()` 传给新解释器；
  删除启动快照之后注入的 `OPENBILICLAW_*`，让新进程重新构建运行时接线。
- 保留调用方显式导出的 worker、推荐 Unix socket／TCP 端口、密码和 provider 配置，
  以及 provider 凭据、项目根目录、PATH。未建立快照时保守保留全部环境。
- `execve` 失败继续抛出真实错误，当前进程环境不变。
- 共享 pytest fixture 在每个用例前重置启动快照、结束后恢复，消除执行顺序依赖。

修改前，跨重启的 4 个新增场景失败；先运行 CLI 启动测试再运行外部环境检测测试，
也会失败（合计 5 failed、1 passed）。修复后这些场景及新增的干净启动场景通过。

真实子进程替换 smoke（未启动实际后端）：

```text

after real execve: []
```

新解释器重建快照后不再将父进程的内部 worker／推荐／图片服务变量识别为外部配置。
