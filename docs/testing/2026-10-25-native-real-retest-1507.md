## 实际发现与修复

- 就绪等待 15 秒过短，改为最多 30 秒；仅此调整未解决后续故障，没有把它记成整轮通过。
  托管连接／初始只读打开超时清理后最多重试一次；保存任务空间身份，仍受总预算约束。
- URL 脱敏后模型无法证明用户明确的 `read.php?tid=` 限制。增加用户原话模板对应的页面内
  路径／参数存在布尔证据，不暴露查询值和其他参数名，也不扩大 origin 或采集范围。
- 来源列表的同步旧浏览器环境检查阻塞 API 主循环。真实测得列表 11.67 秒、并发健康请求
  15.39 秒；改由 FastAPI worker 线程承载。复测列表检查进行时，普通草稿读取 0.201 秒。
- 关闭旧会话后迟到的授权回调仍发送页面命令。关闭后拒绝新普通 CDP／授权，只允许自身
  目标和窗口清理；挂起授权的行为回归先失败、修复后通过。
- 已发布 45 秒计划在后台超时；同一计划只调整诊断预算后，实际冷启动耗时 **61.76 秒**，
  采到 3 条。新 Ego 编制向模型提供 120 秒默认建议；用户明确限制优先，实际计划先试跑
  再审批，历史计划和 DSL 缺省不迁移。Ego 单次入口观察上限同步为 120 秒。
- 独立新来源默认继承同站旧 task space，遇到失效旧空间便无法新建。显式独立来源默认新
  session，profile Cookie 仍共享；已有来源更新及显式会话复用保留，旧身份保护不放宽。
- 超时不再返回空说明；编制失败清除旧成功标记。真实模型 502 又暴露了未捕获的提供者
  异常，现转换为可重试的失败草稿，保留进度，失败不激活来源。
