# v0.3.231 发布记录

## 发布内容

v0.3.231 把 **Instagram 与 TikTok 从实验性来源转为正式可用来源**（产品行为不变：两者仍默认关闭、需在设置里显式启用），并同步 README、项目首页、模块文档、隐私说明、Chrome Web Store listing 与 AMO 元数据。同时带上 0.3.230 之后合入的两项改动：大肥鱼通知文案按人设生成（默认人设更可爱、私信补 `msg[dev_id]`），以及 Ollama embedding 不再依赖聊天 SDK（#318）。

发布准备提交 `728b490a` 已通过 [PR #323](https://github.com/whiteguo233/OpenBiliClaw/pull/323) 合入，main 合并提交为 `13ea1e377a5c34cbbc3898cbf0df47ac42e7ae7c`。
