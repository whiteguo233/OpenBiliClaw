# v0.3.230 发布记录

## 发布内容

v0.3.230 将候选池恢复、多语言界面、蓝鱼实验室实验模式，以及 TikTok / Instagram 插件站点权限默认声明一并发布。TikTok 和 Instagram 的站点访问权限在安装/升级时声明；对应来源仍由用户在插件中开启。

发布准备提交 `b1b88c1e` 已通过 [PR #316](https://github.com/whiteguo233/OpenBiliClaw/pull/316) 合入，main 合并提交为 `6b3ce15fca18daf210c4906b02f980c0427bfe71`。
