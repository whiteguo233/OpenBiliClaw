# 硅基流动 Provider 统一验收（2026-11-06）

本次应用改动位于 `feat/unified-sponsored-providers`，基于 Core v0.3.234，尚未发布新的安装包。真实请求使用已有签名 SDK `sponsored-runtime-2026-11-06.2`，没有重新封装密钥或修改 SDK 策略。

## 配置与路由

免费对话是普通 `llm.instances.<id>`，`provider_type="siliconflow_free"`，模型选择为 `Qwen/Qwen3-8B` 或 `Qwen/Qwen3.5-4B`。默认链、模块覆盖、显式备用、连接测试与自有端点共用现有实现。可创建两个免费实例，分别选择模型并明确设置顺序；未加入链的自有端点不会被自动用于付费兜底。

免费向量独立配置为 `llm.embedding.provider="siliconflow_free"`，固定 `BAAI/bge-m3`、1024 维文本向量。免费 LLM 可搭配本地 Ollama，免费 BGE 也可搭配自有 LLM。沿用旧免费 BGE 的缓存来源标识，切换聊天模型不重建向量空间。

旧 `[llm.sponsored].enabled` 迁移为普通实例及明确调用链。保留自有密钥、模块覆盖和已有本地向量地址；旧全局开关归一为关闭。旧原生实例配置只补入一次可选预置实例，不修改用户的默认链，删除后不会重复添加。初始化、PC Web、扩展、手机端不再展示独立的免费方案表单。密钥到期通知与组件准备仍保留在普通 Provider 设置中。

## 边界与修复记录

- 固定签名合同、Rust/中继信任根和传输安全边界不变；此变更不声称客户端二进制能保证共享密钥不可提取。
- 本次普通免费 LLM 实例声明文本及工具能力；图片理解是独立的可选能力，不包含在这次基本功能验收中。BGE-M3 不声明图片向量。
- 流式取消测试发现 ContextVar 跨消费者 `yield` 残留；已改为只在获取上游片段及关闭流时绑定上下文。
- 草稿连接探测不再安装草稿的进程级 runtime 设置；模型选择来自被探测实例。
- 原测试中依赖“任意空 Registry 被全局免费开关接管”的断言已替换为普通实例路由断言，并保留不暗中使用自有额度的覆盖。
- 手机设置保存其他字段时，不再顺带把旧配置强制转成原生实例；免费 LLM 和向量仍可独立修改，切换会按正常配置队列应用。
- CLI 独立免费向量配置复用已有 Rust 路径或 HTTPS 中继；下载失败保留原配置，不继续写入不可用选择。
- Safari 工作流原测试仍期待 `macos-14`，而基线工作流已使用 `macos-15`；只同步测试预期，未修改发布工作流。
