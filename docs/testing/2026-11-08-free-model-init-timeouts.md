# 免费模型首次历史分析超时修复

状态：`fix/free-model-init-timeouts` 分支验证完成，尚未合入 main 或发布到安装包。基线为 v0.3.235 / `92ac4f22`。

## 复现与根因

用户反馈首次导入历史的「分析偏好」阶段失败。本地使用隔离目录、正式运行时、已发布签名 Rust SDK 和真实硅基流动请求复现：8B 处理 200 条合成历史时，前三次请求分别约 33 / 38 / 38 秒，第四次达到 180 秒请求截止时间后失败。外层为 `PreferenceAnalysisError`，内层为 `SponsoredUnavailableError: sponsored runtime timed out`。该次输入序列化大小 31,477 字节，输出预算 4096，远低于当前仓库配置的上下文窗口；不能把本次失败归因为上下文溢出。

另有确定性回归证明：200 条父批次原先在内部按 prompt 预算递归串行拆分，但只在父批完成后上报进度；内部有成功请求时，初始化看门狗仍可能判断无进展。包裹后的 `SponsoredRequestTooLargeError` 也没有进入原先基于错误文字的拆批分支。小任务的单请求路径缺少同样的恢复。

## 修复行为

- 正常预算拆分提前完成，每个计划批次有限并发执行并报告完成；初始化进度和绝对时间预算使用同一批数。保留既有空闲截止、绝对截止与显式超时覆盖。
- 免费偏好提取关闭未指定的额外思考，输出最多 4096 token；不改其他业务调用的全局思考设置，不修改 Rust / 签名策略 / 凭据。
- 从异常原因链识别免费上下文错误并拆批。仅免费运行时／上游的超时允许一层缩批恢复：多事件顺序处理两半，单事件最多再试一次；持续失败明确报错。鉴权、额度、策略、取消不会进入这一恢复。
- 当前公共 SDK 入口对非流式与流式调用都执行模型上下文校验；仓库配置 8B 为 131072、4B 为 262144，来自既有 2026-10-27 核验，本次没有重新验证官网上限。业务批次预算更小，用于控制长任务延迟。

## 真实请求结果

数据是编程／园艺主题的合成历史，重复扩展并赋予唯一事件 ID、标题序号、时间；不是用户真实历史，也不是 800 个不同主题。没有读取用户 Cookie 或上传真实历史。

路径为：正式 `create_app()` → MemoryManager 入库与查询 → SoulEngine / PreferenceAnalyzer → LLMService → 固定免费实例 → SDK IPC → Rust → 硅基流动 → 初始画像校验和保存。每次调用链仅含被测模型，不使用另一模型兜底。800 条样本额外接入初始化使用的真实进度看门狗与时间预算。它覆盖阶段 2、3，不等于重新验收平台采集、首轮推荐补池和四端浏览器点击全过程。

| 修复前 | Qwen3.5-4B | 200 | 212.21 秒 | 221.15 秒 | 通过 |

800 条样本两模型各有 30 个偏好请求，最大序列化输入均为 33,301 字节；8B 最慢请求 50.24 秒、最长真实进度间隔 48.83 秒，4B 分别为 44.59 秒与 33.84 秒。报告中的其他调用包含画像构建及按需 Embedding，不应全部计为偏好批次。

实际 Rust / IPC 故障注入另用每模型 8 条历史：仅首次偏好请求把客户端等待降到 0.05 秒，确认抛出 `SponsoredUnavailableError` 且 Rust 进程已停止，再恢复原 180 秒上限。两个半批与画像请求均走真实上游，8B 总计 32.28 秒、4B 总计 57.38 秒完成。首条请求可能尚未到达上游，因此这是客户端超时与进程恢复验收，不能称为上游自然故障复现。可在上述脚本参数追加 `--inject-first-timeout --events 8` 重跑；归档报告含注入标记。

每个规模每模型仅一次修复后运行；耗时是单次观察，不是延迟 SLA 或稳定成功率估计。真实运行未触发的恢复分支以可重复故障注入回归验证，不能冒充真实网络故障实测。测试断言画像已保存且兴趣非空，不将其等同于所有画像语义质量全通过。

## 可重复验收

新增 `scripts/sponsored_init_acceptance.py`，只接受不存在的隔离目录，沿用验签安装流程。默认按现有安装流程获取当前签名 SDK，也可传 `--sdk-archive /path/to/signed-archive.tar.gz`；不需要在脚本写入 Key。请求观察器只包装并调用原实现，不替代响应；报告保留耗时、调用标识、大小与错误类型，不含请求正文或凭据。

```sh
PYTHONPATH=src python scripts/sponsored_init_acceptance.py \
  --root /tmp/obc-init-8b-new --model Qwen/Qwen3-8B --events 800
PYTHONPATH=src python scripts/sponsored_init_acceptance.py \
  --root /tmp/obc-init-4b-new --model Qwen/Qwen3.5-4B --events 800
```

首次 200 / 800 条结果来自该脚本的临时前身，使用相同生产组件；归档报告不包含本机配置、签名策略或二进制。整理后的脚本另做真实小样本验证：4B 的 8 条单请求路径通过，分析加画像保存 16.84 秒。原始请求元数据见 [JSON 证据目录](assets/free-model-init-20261108)。
