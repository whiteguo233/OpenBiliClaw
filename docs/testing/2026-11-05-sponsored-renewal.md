# 免费凭据轮换通知与独立向量选择

本次在免费双模型用户流程分支上补充两项能力：组件内置凭据不可用时给出更新/自有Key入口，以及免费对话与云端/本地文本向量独立选择。主程序仍待正式发布；没有撤销或更换生产Key，也没有重新发布Rust组件。

## 行为与验收边界

- AUTH_FAILED 表示服务商拒绝凭据，可能是过期、撤销或权限变化；POLICY_INVALID 表示组件授权失效。配置页和消息页显示持久通知，附最新应用版本链接与自有Key入口。按钮只编辑配置草稿或导航，不自动开启付费调用。
- 限流、网络/上游错误不推断Key到期，不清除先前撤销证据。额度耗尽单独提示，不承诺更新解除配额限制。聊天与向量分别恢复，单次向量成功不能掩盖聊天鉴权失败。
- 文件只保存能力、稳定错误码、观察时间和组件身份哈希；没有Key、Prompt、原始错误正文。通知可跨进程/重启读取；更换组件、关闭免费方案或成功恢复后按相应范围清除/隐藏。
- 初始化、插件、PC、手机和CLI默认云端 BGE-M3，也可选本地 Ollama。保留已有模型、Docker/私有端口；无本地配置时使用 bge-m3 和默认Ollama地址。本地向量独立于免费凭据；两种来源的缓存provenance不同。关闭免费方案后，自有embedding选择不再被保留的本地模式覆盖。
- 本地模型尚未准备好时，初始化先验证免费对话并保存选择，再经原前置检查/修复准备本地向量，不谎报向量已就绪。桌面本地下载/播种恢复生效；已有自部署模型和端点不会被内置seed覆盖。
- 已发行旧应用必须先升级到包含此功能的主程序，才会在后续轮换中显示新通知。没有新增远端轮换推送；撤销通知来自真实请求失败，签名策略到期可在本地识别。

## 页面证据与复验步骤

隔离数据中，使用测试IPC进程模拟AUTH_FAILED；配置草稿没有真实Key。截图：[桌面](assets/sponsored-renewal/desktop.png)、[插件](assets/sponsored-renewal/popup.png)、[手机消息](assets/sponsored-renewal/mobile.png)。

1. 初始化选择免费模型，确认默认云端BGE；改为本地并保存，确认原有Ollama模型/端点保留，未就绪时可进入原向量修复步骤。
2. 用合成IPC peer的 `SPONSORED_MOCK_ERROR_CODE=AUTH_FAILED` 运行隔离后端并测试连接。打开设置和消息中心，检查更新链接、徽标及自有Key操作；重启后通知仍存在。相同通知的状态轮询保持手机通知按钮焦点，不重复重建消息面板。
3. 去掉测试故障，分别完成聊天/向量请求，确认只清除恢复的能力；模拟429确认不提示凭据过期。
4. 关闭免费方案并填写自有embedding，保存后确认使用该选择。本地模式在免费Key失败时仍能走独立Ollama向量。

复验命令：`PYTHONPATH=src python -m pytest tests/test_sponsored_renewal.py tests/test_sponsored_runtime_e2e.py -q`。安装检查：`PYTHONPATH=src python scripts/sponsored_install_smoke.py`。维护者的轮换顺序见[Runtime文档](../modules/runtime.md#免费凭据状态与轮换)。
