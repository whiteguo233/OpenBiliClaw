# 聊天风格模板与三端验收（2026-09-26）

## 交付范围

分支 `feat/chat-persona-picker` 基于 `5498205d`，继承前三轮聊天修复。
在独立 worktree 使用真实模型配置与 SQLite 数据副本，测试服务监听
`127.0.0.1:18439`，定时发现和外部同步关闭；用户现有 AppReview 服务不改动。
所有测试会话、设置与学习写入仅落测试副本，不提交凭据、用户历史或截图数据。

提供自然朋友、简洁直接、温柔倾听、轻松幽默、理性分析、循循善诱六个静态模板。
功能角色与表达风格独立：用户可以组合“系统管家 + 简洁直接”。三端共享后端
目录、说明及同题示例，选择保存在会话 metadata；每条新 Agent 消息冻结自己的
风格，之后的保存不会改变在途回复、重试或重启恢复。模板改变表达，不增加工具权限。
当前用户的篇幅和任务要求优先，简单问题仍直接回答。

## 真实模型请求

六个全新会话采用相同输入：“今天有点累，想休息。请用一两句话回复，不用查询工具。”
全部经过真实 `POST /api/chat/turns` → SSE → durable completed，冻结值逐项匹配，
均无工具调用；实际回答为一至两句。耗时是本轮端到端样本，不代表固定性能承诺。

| 风格 | 完成耗时 | 结果 |
|---|---:|---|
| 自然朋友 | 1.551s | 简短回应休息意愿 |
| 简洁直接 | 1.369s | 简短回应休息意愿 |
| 温柔倾听 | 2.039s | 温和回应 |
| 轻松幽默 | 1.897s | 轻松措辞 |
| 理性分析 | 1.463s | 没有强行展开分析 |
| 循循善诱 | 2.061s | 没有强迫追问或教学 |

这些简单问候的实际风格差异较小；模板是表达倾向，不保证每次输出都像静态示例，
也不为突出“人格”而增加篇幅或额外模型调用。原始六条记录在本机
`/tmp/chat-personas-live-results.json`。
