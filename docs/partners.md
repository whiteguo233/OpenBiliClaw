# 🤝 技术合作伙伴

OpenBiliClaw 是个人维护的开源项目。合作伙伴以模型额度、推理资源或技术服务的方式支持项目持续迭代；合作不改变开源许可、产品形态与本地优先的数据边界。

[硅基流动（SiliconFlow）](https://www.siliconflow.cn) 是面向 AI 应用的基础设施与模型服务平台，提供 OpenAI 兼容的推理 API，覆盖 DeepSeek、Qwen、GLM 等主流开源模型。

### 合作内容

- **模型额度支持**：为项目提供免费模型额度，用于画像整理、记忆合并等辅助任务，让这些后台任务不占用用户自己的 API 预算。
- **真实链路评估**：项目用这些额度在真实业务样例上评估国内开源模型的表现（延迟、稳定性、结构化输出与工具调用），把结论写进 [模型配置](modules/llm.md) 与变更日志，供用户选择模型时参考。
- **品牌展示**：GitHub Pages 项目首页、文档站与 README 展示「Powered by SiliconFlow」合作标识。

### 边界说明

- 合作方不参与推荐算法、画像构建与内容排序的设计与决策；推荐质量仍由项目自身的评估与用户反馈决定。
- 用户数据默认保存在本机 SQLite；合作本身不引入项目方侧的数据收集或遥测。
- 若启用赞助任务，请求由本地 Runtime 直接发送给硅基流动，受其隐私政策约束；OpenBiliClaw 项目方不经过、不保留、不中转这些请求。
- 赞助额度只用于项目侧评估与辅助任务，不改变用户自己配置的模型、调用链路与费用。
